# Triage 标签

这套 skill 使用五个标准 triage 角色。本文将这些角色映射到仓库 issue tracker 实际使用的标签字符串。

| agent-toolkit 里的标签 | 我们 tracker 里的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等报告者补更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完整，可以交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不会去处理 |

skill 提到某个角色时，使用表中对应的标签字符串。

右侧标签列可以按项目实际用词修改。
